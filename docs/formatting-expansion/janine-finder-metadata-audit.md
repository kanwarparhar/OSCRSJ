# Journal Finder — metadata audit sample (Janine pre-launch)

> Handoff: `^handoff-janine-finder-metadata-audit` · Surfaced Session 2 (2026-07-15) · Owner: Janine
> Gates: the `/format` **Journal Finder** section going public. Kanwar controls the push; this audit is the sign-off (or an explicit waive, as the Session-92 formatting audit was waived).

## What this is

The Journal Finder scores every supported orthopedic journal against a manuscript's numbers. Two data sources feed it:

1. **Eligibility + constraint limits** — read directly from the existing `lib/formatting/journals/*.json` rule files (the formatting registry). **Not re-audited here** — this is the same registry whose expansion audit Kanwar waived in Session 92. The Finder's eligibility gate and word/abstract/figure/table/reference deltas come entirely from these and are as trustworthy as the formatter itself.
2. **Enrichment metadata** — `lib/finder/journalMeta.ts`: indexing, open-access model, APC (USD), review speed, and subspecialty scope tags. **This is the new, unaudited data and the subject of this audit.** It affects only (a) the per-result metadata info-line and (b) scope-based ordering when a user picks a subspecialty. It never affects eligibility or the constraint deltas.

## How it was gathered (Session 2)

8 parallel research agents, one batch each, under a strict doctrine: **record a value only if a live page was fetched stating it; cite that URL; unknown/blocked ⇒ null (never guess).** Most publisher sites (Elsevier/SAGE/Wiley/Springer/Wolters Kluwer) block automated fetch, so indexing was largely recovered from the **NLM Catalog** (MEDLINE/PMC), and OA/APC/scope from **DOAJ, Scimago, and journal-own OA pages** surfaced via search — hence most rows are **confidence B** (verified from a secondary live source) rather than A (journal's own primary page).

- 75 journals · **4 confidence A · 70 B · 1 C** (jbjs-reviews)
- 74/75 have scope tags (jpa correctly has none — physiological anthropology is not an orthopedic subspecialty)
- 74/75 have ≥1 verified indexing service · 64/75 have a USD APC

## Please spot-check (≥10 journals) against live Guide-for-Authors / OA / indexing pages

Priority cells: **indexing**, **APC (USD)**, and **case-report acceptance** (the last is derived from the rule file's `article_types`, so a wrong cell means the rule file is wrong).

**Known-null-by-design (not errors) — confirm the reasoning, don't "fix":**
- APC null where the journal quotes only **GBP/EUR** (e.g. bone-joint-research, bmjosem, bmc-sports-science-medicine-rehab) — we don't fabricate a USD conversion.
- `jbjs` and `fai` APC left null to avoid a **collision** with their separate OA sibling titles (JBJS Open Access $2,250; Foot & Ankle Orthopaedics $800/$1,200) — those figures do **not** apply to the flagship titles.
- `oscrsj` indexing `[]` (new journal, pre-index) and APC null (waived before 2026-08-01).

Corrections: edit the matching row in `lib/finder/journalMeta.ts` (keep the `source_urls` honest) and re-run `npx tsc --noEmit` + `npx tsx --test tests/finder-match.test.ts`.
