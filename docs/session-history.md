# OSCRSJ Session History

> Lossless archive of every Cowork session that touched this repo. CLAUDE.md (the living file) carries the 3 most recent sessions full + every session from the last 14 days as pointers + an Open Follow-ups punch list. Historical detail lives here, grep-accessed.
>
> **Anchor convention:** every session entry has a stable block-ref ID `^session-NN-short-slug` resolvable from CLAUDE.md and from cross-references in commit messages or other docs. NN is zero-padded to 2 digits (Session 03, Session 27, Session 46) for grep stability.
>
> **Two access patterns:** (1) sequential — grep `^### Session NN` for any session by number, or scan the chronological Index below; (2) topical — scan the Topic Index for all sessions touching a given workstream (reviewer pipeline, email infrastructure, editorial decisions, etc.).
>
> **Find a session:** `grep -nE "^### Session [0-9]+" docs/session-history.md` for the chronological index, or `grep -nE "^### " docs/session-history.md | head -30` to scan section heads + topics.
